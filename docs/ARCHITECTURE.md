# SalesAIGuide.com — Architecture

Read-only architecture survey of the live site. Captures the system as currently built so future work shares full context. Last mapped 2026-06-09.

The site is a static, hand-templated affiliate review site for B2B sales tools. Its defining feature is a ~2,200-line Python "indexation gate" that grades every page A/B/C and decides what gets indexed, wired into a guarded Netlify deploy and a weekly automated agent cycle.

## 2. Tech stack

- Static HTML, no JS framework, no runtime templating. Pages are pre-generated `.html` committed to the repo.
- Hosting: Netlify (publish dir = repo root), one serverless function (`netlify/functions/subscribe.js`).
- Tooling: Python 3 stdlib (the gate + ~40 fix/migration scripts). Node only for `canvas` (OG-image gen) and the ATLAS agent runner.
- Analytics: GA4 (`G-VRBZ6Z6885`) on 100% of pages.
- Sources of truth: `affiliate-links.json` (all `/go/` routes) and the `.html` files. Sitemaps, `_headers`, `gate-report.json` are GENERATED (gitignored).

## 4. Page template anatomy (the gate keys off this)

- `<head>`: clean-URL `<link rel=canonical>`, OG + Twitter card, typed JSON-LD: `Review` (reviews), `ComparisonChart`+`FAQPage` (comparisons), `WebSite`+`SearchAction`+`Organization` (home), `BreadcrumbList` everywhere. Ratings render as unscored `Review` (AggregateRating is explicitly gate-failed).
- `data-audit` zone attributes are the gate's contract: `core-editorial` (protected editorial body), `sources-checked`, `last-verified`. Section classes: `quick-summary`, `summary-grid`, `pricing-table`/`pricing-tier`, `verdict`, `specs-cta`, `review-hero`.
- Freshness labels: "Updated June 2026" (hero) + "Last verified: Jun 2026" (footer/header). Load-bearing for the gate's staleness signal.

## 5. Routing (static + Netlify rules)

- Clean URLs: `.html` stripped via 301s.
- `/go/*` affiliate block in `_redirects` (302s), generated by `build_redirects.py` from `affiliate-links.json`. Aliases supported.
- Legacy 301s: `/blog* -> /resources/`, `/methodology -> /disclosure`.
- Noindex (via `_headers`): `/go/*`, `/ops/*`, `/404.html`. `robots.txt` disallows `/go/` and `/ops/`.

## 6. The "lead/checkout" flow = affiliate monetization

No on-site purchase. Conversion = an outbound click through a tracked redirect. Click path: content CTA -> `/go/{slug}` (302, noindex) -> vendor URL (+tracking if live).

- `affiliate-links.json`: 49 slugs, 4 LIVE, 45 placeholder.
  - LIVE: `woodpecker` (`red=salesa145703`), `fireflies` (`fpr=matthew16`), `justcall` (`fp_ref=matthew95`), `saleshandy` (`via=matthew`).
  - 45 placeholders redirect to clean vendor URLs with NO tracking param (earn nothing). Documented root cause of $0 revenue.
- Direct-vs-tracked tradeoff (gate-enforced): on reviews almost every CTA is a DIRECT untracked vendor link; only the single `specs-cta` link stays tracked `/go/`, because the gate bans `/go/` from the `core-editorial` zone (Signal 7). Comparison-page tool links keep `/go/`. ~1 tracked link per review vs 7-8 direct.
- Sticky CTA (`js/sticky-cta.js`): floating bar built from the hero, uses the tracked `/go/` link. Second tracked surface.
- Email capture (two systems): Beehiiv on home/about via `netlify/functions/subscribe.js` (fires a GA `newsletter_signup` event); ButtonDown embedded forms on many `best/ compare/ pricing/` pages (post straight to ButtonDown, so those signups are GA-invisible).

## 7. Analytics (GA4 `G-VRBZ6Z6885`)

- Coverage: 100% of pages, verified across every directory.
- Custom events in `js/main.js`: `affiliate_click` (only on `/go/` links, so direct CTAs are untracked), `newsletter_signup` (Beehiiv only; appears to include the email value, a PII-in-GA concern), `scroll_depth`, `time_on_page`.
- Absent: GTM, Clarity, Plausible, Meta Pixel, session recording, any vendor-side conversion pixel.
- Net: traffic and engagement are measured; revenue cannot be attributed. Sees "visited Woodpecker review," not "signed up for Woodpecker." Direct CTAs and ButtonDown signups are blind spots.

## 8. SEO files

- Sitemaps: `sitemap.xml` is an index referencing `sitemap-core.xml` (165 URLs, A+B, indexed). `sitemap-hold.xml` = 1 URL (404, noindex). Themed sitemaps exist (reviews 33, comparisons 59, categories 11, editorial 29). All generated by the gate.
- `robots.txt`: allow-all except `/go/`, `/ops/`; points to `sitemap.xml`.
- `_headers`: security + cache (1yr immutable for `/css`,`/js`) + generated `X-Robots-Tag: noindex` block for C pages.
- `feed.xml`: RSS of reviews. Stale (Mar 2026), uses `.html` links. Minor.

## 9. The indexation gate (`scripts/indexation_gate.py`, ~2,200 lines) — the heart

Grades every page, decides indexation, generates sitemaps + headers + report. Treat as READ-ONLY policy.

- Tiers: A (flagship; strict word/source/similarity thresholds, last-verified <= 90d), B (indexed; looser, last-verified <= 365d), C (noindex; any hard-fail or critical slop signal).
- Hard fails (-> C): empty H2 sections, missing verdict, verdict hidden in `<details>`, AggregateRating schema, below per-type word/source/domain/internal-link minimums, missing/mismatched canonical, too-high similarity (reviews >= 0.25, comparisons >= 0.30).
- Slop signals (post-grade): (2) thin sections, (3) unsourced blockquotes, (4) unsourced numeric claims (`$`/`%`/`x` need adjacent https citation), (5) over-templated intros (Jaccard vs cluster peers), (6) hype density > 2%, (7) conversion_first (`/go/` in core-editorial or before verdict), (9) last-verified staleness (>90d caps at B, >365d -> C).
- Key constants: `CONTENT_CLASSES`, `ALLOWED_GO_ZONES = {quick-summary, summary-grid, pricing-table, pricing-tier}`, `AFFILIATE_RE`.
- Outputs: `sitemap.xml`, `sitemap-core.xml`, `sitemap-hold.xml`, `_headers`, `gate-report.json`. Exit codes: 0 clean / 1 C among reviews+comparisons / 2 an A downgraded by slop.

## 10. Build + deploy pipeline

`deploy.sh` (only sanctioned manual deploy):
1. Identity guards (abort on mismatch): git remote ends `salesaiguide.git`; `.netlify/state.json` siteId match; `index.html` contains "Sales AI Guide".
2. `build_redirects.py` (regenerate `/go/` block from JSON).
3. `check_affiliate_links.py` (fail on fake `?ref=salesaiguide`, undefined slugs, out-of-sync `_redirects`; warn on bare CTAs).
4. `scrub_pii.py --check` (fail if owner PII leaks; April scrub replaced Person author schema with Organization).
5. `indexation_gate.py` (grade + generate artifacts).
6. `netlify deploy --dir . --prod`, then post-deploy curl checks.

`netlify.toml`: publish `.`, build command runs the gate, full security headers (HSTS, CSP, X-Frame-Options) + cache rules. `package.json`: `build`/`gate`/`test` scripts; dep `canvas`. `.gitignore`: the generated artifacts.

## 11. CI / automation (`.github/workflows/`)

- `deploy.yml`: on push to `main` (and `redesign/nerdwallet-v1`), runs `npm run build` (the gate) then deploys via `nwtgck/actions-netlify`. Only `main` is production.
- `atlas-weekly.yml`: cron Sundays 06:00 UTC, runs `node scripts/atlas.js` (the "ATLAS" weekly content-agent cycle: auto-fix slop, audit, bump freshness, verify pricing, auto-commit/push). `ATLAS_DRY_RUN` toggle.

## 12. Script toolchain (`scripts/`, ~44 files)

- Pipeline (every deploy): `indexation_gate.py`, `build_redirects.py`, `check_affiliate_links.py`, `scrub_pii.py`.
- Recurring maintenance: `bump_last_verified.py`, `fix_conversion_first.py`, `generate_feed.py`, `atlas.js`, `agent-autofix.js`, `weekly-run.sh`, `test_slop_signals.py`.
- One-off migrations (historical, many `_v2..v5`): similarity reducers, internal-link adders, schema injectors, title/canonical/alt-text fixers, intro de-boilerplate, CTA migrators. Accreted cleanup passes, not part of the live build.

## 14. Current health snapshot (gate run 2026-06-09)

- 160 A / 5 B / 1 C of 166. The only C is `404.html` (missing canonical, expected). 165 indexed.
- SEO indexation health: excellent. Freshness labels all June 2026.
- Revenue: still ~$0, but the cause is NOT content or indexation now. It is (a) only 4 of 49 affiliate programs are live, and (b) ~zero organic traffic / low domain authority. Distribution is the real bottleneck; the gate work removed the technical blockers.

## 15. Known gaps / risks / cruft

- Conversion tracking is blind: no vendor pixel; direct CTAs and ButtonDown signups untracked. Cannot prove affiliate ROI.
- Monetization concentration: 4 live programs; 45 placeholders earn nothing.
- Two newsletter systems (Beehiiv + ButtonDown) with inconsistent GA visibility.
- Cruft: empty literal dir `{css,js,tools,comparisons,categories,blog,images}/` at repo root (brace-expansion accident); stale `feed.xml`; ~40 one-off `fix_*_vN.py` scripts.
- Possible PII-in-analytics: `newsletter_signup` may pass the raw email to GA4 (per `js/main.js`); confirm against the privacy policy.
